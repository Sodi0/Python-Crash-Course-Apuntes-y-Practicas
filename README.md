## 📚 Contenido del Repositorio

Este repositorio contiene material completo del curso Python Crash Course, organizado por temas con apuntes detallados y ejercicios prácticos.

### Módulos Disponibles

- [**Introduction to Programming with Python**](./Class-01-Fundamentos/README.md) - Fundamentos, sintaxis, operadores, PEP 8 y Zen de Python
- [**Git Intro**](./Class-02-GIT/README.md) - Control de versiones, comandos básicos, flujo de trabajo y buenas prácticas
- [**Built-in Types**](./Class-03-TiposDatos/README.md) - Tipos de datos, mutabilidad, strings, operadores y conversión de tipos
- _Más módulos en desarrollo..._

## 💻 Requisitos

- **Python 3.8+** instalado
- Editor de código (VS Code, PyCharm, etc.)
- Git para control de versiones

### Verificar instalación
